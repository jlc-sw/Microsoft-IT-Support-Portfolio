\## Lab Approach



The portfolio contains practical lab evidence rather than certification notes alone.



Each case study may include:



\- Configuration evidence

\- Sanitised screenshots

\- Troubleshooting scenarios

\- Incident documentation

\- Root-cause analysis

\- Resolution or escalation decisions

\- Technical notes



All users and support scenarios shown in the portfolio are fictional and created specifically for lab use.
