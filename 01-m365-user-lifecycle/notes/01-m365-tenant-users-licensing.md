Microsoft 365 LicenceConfirmed that an identity can exist and be permitted to sign in while having no Microsoft 365 Business Premium entitlement.### Blocked Sign-InIdentified an administratively blocked account as the root cause of a sign-in problem and restored sign-in access.### Deleted User RecoveryLocated a recently deleted identity under Deleted users and restored the original account instead of creating a replacement identity.### Microsoft Service HealthReviewed active Microsoft 365 advisories and practised distinguishing a known Microsoft service issue from an individual user, device or application problem.## Service Desk Principles Practised- Establish symptoms before assuming a cause- Establish whether one or multiple users are affected- Verify that the identity exists- Check sign-in state- Check licence entitlement- Check Microsoft Service Health when wider impact is reported- Avoid repeating remediation without evidence- Apply least privilege- Avoid unnecessary tenant-wide changes- Escalate changes that are outside scope, permissions or acceptable risk- Record only confirmed findings in ITSM documentation## Key Lessons- Identity and product licensing are separate- Product licensing and administrative privilege are separate- A valid password does not override a blocked sign-in state- A password reset should not be repeated automatically when the original reset did not resolve the problem- Service Health is evidence, not an automatic diagnosis- Administrative roles should match job responsibilities- Recently deleted identities should be checked for recovery before creating replacement accounts- Troubleshooting should not introduce unnecessary impact to working users## Portfolio Evidence-
